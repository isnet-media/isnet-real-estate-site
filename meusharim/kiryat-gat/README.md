# Kiryat Gat classes board

Same discovery, carousel, filtering and course-detail UI as Ashdod/Yavne.

120 reviewed groups and programmes. Municipal facts are from the official 2026–2027 annual booklet (physical page number in each record). Private swimming programmes use the operator’s current programme pages. This is verified coverage of these sources, not a claim that every private class in the city is included.

Unclear timetable associations and unpublished prices remain unknown. All registrations require confirmation with the operator. No inferred availability. Private pool groups may run at several sites; the Kiryat Gat location must be confirmed. Campus Neviim opening remains unconfirmed. Descriptions are original factual summaries.

Images are local JPG files and explicitly illustrative. Reused ISNET activity images retain illustrative attribution. AI illustrations are credited as AI. The carousel asset is the existing neutral activity quartet. No image is represented as a photograph of the actual Kiryat Gat group.

`assets/classes/cycling-skating.jpg` was generated with the built-in image generation tool, inspected and converted to JPG. Prompt: photorealistic editorial illustration of unbranded bicycle, skateboard, inline skates, helmets and protective pads on an empty outdoor practice court; warm natural light; no people, text, logos or geographical identifiers.

Rebuild catalogue: `python scripts/build_kgat_classes.py`. Validate: `python scripts/test_kgat_classes.py` and Node syntax checks. Monthly source monitoring compares the reviewed booklet content hash and flags changes for editorial review; it preserves catalogue facts and verification dates rather than pretending to recollect changed timetables. Private operator changes still require editorial review.
