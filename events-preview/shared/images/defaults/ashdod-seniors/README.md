# Ashdod seniors photo bank

Upload the 12 optimized WebP files from `isnet_ashdod_photo_bank_12.zip` directly into this directory, preserving filenames. The images are 640x360, quality 76, and total approximately 230 KB. They are AI-generated illustrations, not authentic event photos; do not describe them as documentary images of an event.

The Ashdod frontend maps specific senior activity titles to these files. When an image is absent or fails to load, it falls back to the existing subcategory SVG, then the category image. Verified original event photos take precedence.

Trip illustration rule: show participants and guide from behind, with no recognizable destination or landmark.

Files: senior-guided-tour.webp, senior-painting.webp, senior-lecture.webp, senior-live-music.webp, senior-fitness.webp, senior-theater.webp, senior-board-games.webp, senior-cinema.webp, senior-cooking.webp, senior-digital.webp, senior-handcraft.webp, senior-social-coffee.webp.
