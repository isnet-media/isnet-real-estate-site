# Ashdod sports — results and statistics

Public static site at `/sports/ashdod/`, hosted through the same ISNET GitHub Pages publication as events and enrichment classes. All links and assets are relative. The published dataset is the verified snapshot from 14 October 2026; no unattended sports refresh is configured yet.

The site includes football adults, football youth, basketball, handball and round results. Logos and licensed Heebo fonts are bundled. The original development source is retained in the Sites source repository.
